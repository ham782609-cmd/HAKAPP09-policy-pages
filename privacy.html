개인정보 처리방침

최종 업데이트: 2026-10-30

1. 기본 원칙

급하다급해(이하 "서비스")는 가까운 화장실 검색, 도보 길안내, 화장실 정보 등록·제보 기능을 제공하기 위해 필요한 범위에서만 정보를 처리합니다.

서비스는 회원가입과 로그인이 없으며, 이름·전화번호·이메일을 필수로 요구하지 않습니다. 등록·제보·신고의 반복 요청과 악용 방지를 위해 아래의 설치별 임의 식별값을 처리합니다. 광고나 이용자 추적(트래킹)을 하지 않으며, 정보를 판매하지 않습니다.

2. 처리하는 정보와 목적

  • 위치 정보: 기기의 현재 위치는 주변 화장실 검색과 도보 길안내에 사용합니다. 지도에서 선택한 장소의 좌표는 주소와 건물 경계 조회에 사용합니다. 위치 권한은 앱을 사용하는 동안에만 요청합니다.
  • 등록·제보 정보: 이용자가 직접 입력한 화장실 이름, 장소 좌표, 주소, 층, 운영 시간, 이용 가능 여부, 비밀번호 필요 여부와 작성 시각은 서버에 저장되며 다른 이용자에게 표시됩니다.
  • 정보 신고: 선택한 신고 사유, 대상 장소 ID와 접수·처리 시각을 서버에 저장합니다. 신고할 때 기기의 현재 위치는 첨부하지 않습니다.
  • 설치별 임의 식별값: 등록·제보·신고 기능을 처음 사용할 때 무작위 값을 생성해 기기에 저장합니다. 요청 시 서버로 전달하며 서비스 데이터베이스에는 SHA-256 해시를 보관합니다. 반복 요청 제한, 악성 등록 차단과 처리 내역 확인에 사용합니다. 하드웨어 식별값·광고 식별값은 사용하지 않으며 광고나 다른 앱의 활동과 연결하지 않습니다. 앱 데이터 초기화나 재설치 시 새로운 값이 생성될 수 있습니다.
  • 기기 내 저장: 화면 설정 등 앱 이용에 필요한 일부 값은 기기 안에만 저장됩니다.

3. 보관 기간

검색과 길안내에 쓰인 현재 위치는 요청을 처리하는 데에만 사용하며, 서비스 데이터베이스에 따로 저장하지 않습니다. 다만 서버 운영 기록에 요청 정보가 일시적으로 남을 수 있습니다.

등록·제보 정보는 화장실 정보를 제공하기 위해 서비스 운영 기간 동안 보관하며, 정정·삭제 요청이 있으면 확인 후 수정하거나 삭제합니다.

요청 제한용 기록은 30일, 신고 기록과 공개 등록·제보에 연결된 설치 식별 해시는 최대 90일 보관합니다. 설치 해시 관리 정보는 마지막 이용 후 90일이 지나고 차단 기간이 종료되면 삭제합니다. 악성 요청 차단은 운영자 확인 후 최대 90일간 적용할 수 있습니다. 만료 자료는 매일 정리합니다. 기기의 앱 데이터 삭제만으로 서버에 남은 신고·제보가 즉시 삭제되지는 않으므로 필요한 경우 문의처로 삭제를 요청해 주세요.

4. 외부 서비스 이용(처리 위탁)

서비스는 기능 제공을 위해 아래 외부 서비스를 이용하며, 기능에 필요한 좌표와 요청 정보가 해당 서비스로 전달됩니다.

  • Supabase: 화장실 검색, 등록·제보·신고 저장, 반복 요청 제한 및 서버 기능 운영
  • 네이버 지도(NAVER Cloud Platform): 지도 표시와 주소 조회
  • TMAP: 도보 경로 계산
  • 브이월드(국토교통부): 건물 경계 조회
  • Shorebird: 앱 업데이트 제공

5. 이용자의 권리

이용자는 기기 설정에서 언제든지 위치 권한을 변경할 수 있습니다. 위치 권한을 허용하지 않아도 서울 강남역 주변을 둘러볼 수 있습니다. 서비스 지역 밖에서는 서울 지도 보기 버튼으로 이동할 수 있습니다. 둘러보기의 기준점은 실제 내 위치로 표시하지 않으며, 길안내는 서울 지역의 실제 위치를 확인한 뒤 이용할 수 있습니다.
